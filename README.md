# Letterwise

Letterwise is a free word-guessing game for Android with 25,000 answers built in: a Daily Puzzle, Classic with 4 to 7 letters, Word Fever, Secret Word, Quad, two players on one phone or two, stickers, badges and a home-screen widget. No adverts, no account, no internet needed.
